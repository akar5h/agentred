# Release process

Releases cut from `main` every Tuesday and Thursday at 14:00 UTC. Hotfixes
go via a release branch off the most recent tag; do not cherry-pick into
`main` and re-cut.

## Steps

1. Verify CI is green on the commit you intend to tag
2. Open the release PR generated by the bot (auto-titled `release/<date>`)
3. Two approvals required, at least one from the on-call
4. Merge — the deploy pipeline picks it up automatically
5. Watch the canary dashboard for 20 minutes before walking away

## Rollback

The deploy pipeline keeps the previous three images warm. `deploy rollback`
takes a single arg: the tag to roll back to. Use it; do not redeploy an
older commit by hand.
